============================================================
 WHAT TO DO ABOUT PDF CONVERSION
============================================================

arXiv needs PDF or LaTeX, not .md. Fastest path:

  pip install pandoc   (or download from pandoc.org)
  pandoc paper.md -o paper.pdf --pdf-engine=xelatex -V geometry:margin=1in

Or use Overleaf: paste the markdown content, format minimally, export.

The paper is structured with ## headings, tables, and code blocks —
pandoc handles these well out of the box.
